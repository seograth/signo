## 🙏 Special Acknowledgments & Open Source Technologies

Signo is made possible thanks to the amazing open-source ecosystem:

- **Google MediaPipe**: Real-time 3D hand tracking solution.
- **TensorFlow.js**: In-browser neural network classifier execution.
- **Three.js**: 3D graphics and procedural avatar rendering engine.
- **Material-UI (MUI)**: Component UI framework and accessible design system.
- **Vercel**: High-performance hosting and web analytics platform.
